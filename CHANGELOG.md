# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [0.1.0] — 2026-10-03

Первый релиз.

### Добавлено

- Клиент `Atlorium\Client`: PHP 7.4+, без обязательных зависимостей (`ext-curl`, `ext-json`), работа без
  Composer через `autoload.php`.
- Все 23 сервиса Atlorium, 59 методов: ЕГРЮЛ/ЕГРИП, БИК, SWIFT, BIN, AML, профиль IP, ГАР/ФИАС,
  стандартизация адреса, телефон, e-mail, OCR, DNS, CIDR, cron, SSL, погода, ИИ-чат, прямой и обратный
  геокодинг, тестовые данные, проверка ссылок, аудит сайта, модерация изображений.
- Иерархия исключений по HTTP-статусам, ретраи на 429/503 и сетевых ошибках с учётом `Retry-After`.
- `PermissionDeniedException` — ответ 403: сервис не входит в условия учётной записи
  (код `service_not_in_account_terms`). Не повторяется.
- `ServiceUnavailableException` (503) — наследник `ServerException`: `catch (ServerException $e)` ловит любую
  ошибку 5xx. Метод `isMaintenance()`; 503 с кодом `service_disabled` или `maintenance` (плановые работы)
  не повторяется, прочие 503 повторяются как раньше.
- `getRetryAfter()` у любого исключения с HTTP-ответом.
- Метаданные ответа через `withRawResponse()`.
- Транспорты: `CurlTransport` (по умолчанию, с опциями cURL), `Psr18Transport`, `MockTransport` для тестов.
- Изображения для OCR и модерации — из пути, байтов, потока или `\SplFileInfo`; правила разбора строки описаны
  в README.
- Демо-режим без ключа на публичном sandbox-ключе; если ключ не задан вовсе — одна запись в `error_log()`
  за процесс.
- POST после сетевой ошибки повторяется, только если соединение не установилось (DNS, отказ в соединении,
  таймаут подключения): повтор после таймаута чтения мог бы выполнить платную операцию второй раз.
  `CurlTransport` отличает таймаут подключения от таймаута чтения.
- Настройка `maxRetryDelay`: при обработке веб-запроса SDK ждёт перед повтором не больше 10 с (в CLI — 120 с).
- `ConnectionException::isRequestNotSent()`.
- Base64 с переносами строк принимается как Base64; ссылка вместо изображения — понятная ошибка.
- Таймаут `aichat->send` по умолчанию — 660 с (11 минут): развёрнутый ответ модели может готовиться до 10 минут.
- API-ключ помечен `#[\SensitiveParameter]` (PHP 8.2+ скрывает его в трассировках стека).
- `aichat->deleteSession()` всегда возвращает строку: и на текстовый ответ, и на JSON-объект, и на пустое тело.
- Заголовки вызова объединяются без учёта регистра имени; `Authorization` нельзя перекрыть ни в каком
  регистре.
- Zip-архив релиза для проектов без Composer: одна папка `atlorium-php/` с `autoload.php`.
